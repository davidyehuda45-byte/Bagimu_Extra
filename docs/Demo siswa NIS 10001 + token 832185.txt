Akun demo dibuat via seeder (jangan commit token asli ke repo).

- Admin: admin@sekolah.sch.id / password (dibuat DatabaseSeeder, diblokir di production).
- Siswa: buat via `php artisan db:seed`, token ditampilkan sekali di output seeder.
  Ambil token aktif via TU di menu Direktori Siswa → Token, atau cetak Kartu Login.

Contoh lama (NIS 10001) sudah tidak valid karena token dirotasi tiap seed.
