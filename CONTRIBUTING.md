# Panduan Kontribusi - Bagimu Extra

Terima kasih telah berkontribusi pada pengembangan aplikasi **Bagimu Extra** (SMK Bagimu Negeriku).

## Alur Kerja Pengembangan
1. Buat branch baru dari main dengan format:
   - eat/nama-fitur untuk fitur baru
   - ix/nama-bug untuk perbaikan bug
   - docs/nama-dokumen untuk pembaruan dokumentasi
2. Lakukan pengujian lokal sebelum mengajukan Pull Request.
3. Buat Pull Request ke branch main.
